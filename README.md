# Z4W3R14 — Contos de Terror e Suspense

Um site dedicado a histórias sombrias, terror psicológico e suspense sobrenatural.

## Como funciona

Cada conto é uma página própria com imagem de capa, texto da história e espaço para vídeo. Tudo é estático e hospedado no GitHub Pages.

## Quer adicionar um conto?

1. Crie um arquivo HTML na pasta `contos/` (use `contos/o-espelho-que-chora.html` como modelo).
2. Coloque imagens em `assets/img/` e vídeos em `assets/video/`.
3. Adicione o conto ao array `contos` em `script.js`.
4. Faça commit e push para o branch `main`. O GitHub Pages atualiza automaticamente.
