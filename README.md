# Z4W3R14 — Contos de Terror e Suspense

Um site dedicado a histórias sombrias, terror psicológico e suspense sobrenatural.

## Como funciona

Cada conto é uma página própria com imagem de capa, texto da história e espaço para vídeo. Tudo é estático e hospedado no GitHub Pages.

## Quer adicionar um conto?

1. Crie um arquivo HTML na pasta `contos/` (use `contos/o-espelho-que-chora.html` como modelo).
2. Coloque imagens em `assets/img/` e vídeos em `assets/video/`.
3. Adicione o conto ao array `contos` em `script.js`.
4. Faça commit e push para o branch `main`. O GitHub Pages atualiza automaticamente.

## Gerando imagens gratuitas (sem gastar nada)

Use qualquer gerador de imagem gráfico gratuito:

- [Bing Create (DALL-E 3)](https://www.bing.com/create) — Microsoft, gratuito com conta Microsoft
- [Leonardo.ai](https://leonardo.ai) — créditos diários gratuitos
- [Craiyon](https://www.craiyon.com) — completamente gratuito

**Prompt sugerido para terror:** `dark horror mirror, cracked old bathroom mirror, scary reflection reaching out, dim yellow light, horror atmosphere, cinematic, photorealistic`

Salve as imagens geradas em:
- `assets/img/conto-o-espelho.jpg` (ou .png)
- `assets/img/conto-a-ultima-foto.jpg` (ou .png)

E atualize o caminho em `script.js` e nos arquivos HTML de cada conto.

## Vídeos

Vídeos também podem ser adicionados em `assets/video/` e referenciados na tag `<video>` de cada conto.
