Sobre este site

Bem-vindo ao Z4W3R14, um espaço dedicado a contos de terror e suspense.

Aqui o foco está nas histórias: sombrias, inquietantes, feitas para ler com a luz acesa.

Cada conto pode ter imagem de capa e vídeo. Para adicionar uma nova história, basta criar um novo arquivo na pasta contos/ e enviar para o repositório. O site é hospedado gratuitamente pelo GitHub Pages.

Se você escreve terror, envie seu conto. Se você só gosta de ler, fique à vontade.
